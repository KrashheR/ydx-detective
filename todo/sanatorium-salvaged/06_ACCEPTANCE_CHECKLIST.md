# Чек-лист приёмки

## Сюжет

- [ ] Все десять локальных страховых дел понятны без знания всей арки.
- [ ] Каждое дело продвигает общую тайну ровно на один заметный шаг.
- [ ] Лебедев подозрителен, но не доказан до дел 8–9.
- [ ] Возвращение Павла заранее подготовлено минимум тремя независимыми следами.
- [ ] Вера, Нина и Борис лгут по разным человеческим причинам, а не одинаково «потому что сценарий».
- [ ] Финал различает исходный подлог ради спасения санатория и последующее хищение.
- [ ] Марина не прощает отца мгновенно.
- [ ] Юмор не разрушает эмоциональные сцены.

## Детективная логика

- [ ] Каждый правильный штамп опровергает точную фразу заявления.
- [ ] Нейтральные улики нельзя ошибочно трактовать как обязательные противоречия.
- [ ] Все три финальных ответа доказаны до выбора.
- [ ] Нет финального факта, появляющегося только в признании злодея.
- [ ] Метаданные улик не спойлерят правильный ответ.

## Контент и код

- [ ] 10 дел зарегистрированы в отдельном pack/campaign.
- [ ] 50 улик проходят фактическую Zod-схему.
- [ ] Все ID уникальны и стабильны.
- [ ] Существующие бесплатные дела не изменили порядок и результаты.
- [ ] Интерактивные типы корректно сохраняют прогресс.
- [ ] Есть fallback при неподдерживаемом интерактиве, но он не попал в релиз незаметно.
- [ ] Покупка восстанавливается после перезапуска.
- [ ] Прямой URL не обходит entitlement.
- [ ] Эпилог открывается только после правильного финала.
- [ ] Старые сейвы мигрируют без потери прогресса.

## Визуал

- [ ] Постоянные герои узнаваемы на всех изображениях и в двух возрастах.
- [ ] Павел имеет одинаковые шрам и дефект зуба в ключевых уликах.
- [ ] Лебедев 1998 и 2026 годов считывается как один человек.
- [ ] Документы визуально различаются: медкарта, накладная, договор, пропуск и журнал не выглядят одним шаблоном.
- [ ] Вырез на фотографии физически совпадает с возвращаемым фрагментом.
- [ ] На обложке нет сюжетного спойлера.

## UX

- [ ] Игрок понимает, что покупает завершённый сезон, а не десять случайных уровней.
- [ ] На карте всегда видно количество завершённых дел.
- [ ] После каждого дела есть короткая эмоциональная награда и новый вопрос.
- [ ] Ошибка в финальном обвинении даёт осмысленную подсказку, а не заставляет перепроходить десять дел.
- [ ] Финальные реплики можно перечитать в архиве.

## Финальный smoke test

1. Новый игрок видит locked pack и не может войти в дело 1.
2. Dev entitlement/реальная покупка открывает только дело 1.
3. Последовательное завершение открывает дела 2–10.
4. Reload после любого дела сохраняет прогресс фото.
5. Все 15 используемых типов улик открываются без ошибок.
6. Неправильный финальный ответ не ломает состояние.
7. Правильные три ответа открывают эпилог и награду.
8. Повторный вход показывает completed state и позволяет перечитать дела.
