# Итоговые окна завершения дела

В комплект входят два утверждённых состояния интерфейса и задание на их интеграцию в существующий проект.

## Что использовать

- **Успех:** `reference/success_final.*`
- **Ошибка:** `reference/failure_rewarded_locked_final.*`
- **Задание разработчику:** `CLAUDE_IMPLEMENTATION_PROMPT.md`

PNG показывает целевую композицию на 1920×1080. SVG нужен для точной геометрии и редактирования. HTML демонстрирует адаптив, интерактивные состояния и motion, но не предназначен для прямого копирования в production.

Важно: в `success_interactive_reference.html` присутствует старое тестовое состояние провала. Оно оставлено только потому, что успех реализован в общем прототипе. Для актуального провала использовать исключительно `failure_rewarded_interactive_reference.html` и файлы `failure_rewarded_locked_final.*`.

## Принятая продуктовая логика

- Успех открывает следующее дело и предлагает добровольно удвоить награду за rewarded ad.
- При ошибке точная пропущенная улика скрыта; rewarded ad открывает только подсказку.
- Игрок всегда может бесплатно повторить дело без подсказки.
- Следующее дело блокируется до правильного прохождения, но никогда не блокируется обязательным просмотром рекламы.
- Успешное прохождение требует правильного вердикта и обязательных доказательств.
